# Architecture Decision Records (ADRs)

This folder documents the key engineering and modeling decisions made in
this project — **what** was decided, **why**, and the **trade-offs**.

Each record follows a simple format:

- **Context** — the problem or question we faced
- **Decision** — what we chose to do
- **Consequences** — the resulting pros and cons
